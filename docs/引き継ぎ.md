## 対象と全体像

川崎港 東扇島 −12m 岸壁 第3バース 桟橋部（直杭式横桟橋、1 ブロック 26 m × 16 m、鋼管杭 20 本）。
寸法は設計計算書〔図面集〕（S60.3）のスキャンから読み取り、地盤定数・材料・荷重・判定基準は仮定（入力は examples/kawasaki_probability_L1.yaml）。

1. 変状連鎖図（港空研資料 No.1328 の図-3.4 に基づく。rcframe/pier_chain.py・chain_draw.py、docs/make_henjo_rensa.py）
2. 重点シナリオ S1〜S5 に確率分布を与えた確率評価（D1〜D5、examples/kawasaki_deterioration.py → kawasaki_deterioration/）
3. 港湾施設の利用可否判断に係るガイドライン 第2版（国土交通省港湾局、令和8年5月）の表 D-1・表 D-5 に合わせた判定（G1〜G4、
   examples/kawasaki_guideline.py → kawasaki_guideline/、報告書.html）

## 主な結果（各 200 回の抽出、利用可 / 注意事項あり / 利用不可）

- L1 地震後: 0 年 92.0/0/8.0%、40 年 82.0/0/18.0%、60 年 51.5/0/48.5%
- L2 地震後: 0 年 3.0/0.5/96.5%、40 年 2.0/0/98.0%、60 年 1.5/0/98.5%
- 常時（劣化の全部）: 40 年 98.0/0/2.0%、60 年 78.5/1.0/20.5%（主に接岸力 500 kN の不足、杭の腐食 S2 による）
- L1 の利用不可の主因は余震（kh 0.15）に対する余裕の不足（60 年で 47%）と杭の局部座屈（24.5%、うち杭頭だけ 37/49）。
  杭頭側の腐食量 7〜10 mm で利用不可 78%、10 mm 以上で 100%
- 余震の許容震度を決めた部材（L1、余震が理由の利用不可。results の CSV の allow_aftershock_by から集計、報告書にはない値）:
  0 年 梁の Mu 16・杭 0、40 年 梁 22・杭 14、60 年 梁 23・杭 71（0 年の梁の 16 件は地震だけで生じる不足、増えるのは主に杭）
- 利用方法（1-A・2-A・3-C）の可否は地震後の全抽出で同じ。杭頭の限界曲率の超過を許しても判定は変わらない
- 残留水平変位の閾値 A（L1）: 0 年 0.117 m → 40 年 0.013 m → 60 年 0.017 m。0 年の A を 60 年に使うと 38.9% を見逃す。
  表 A-1 の δy = My·L²/(6EI)（L 列 0.054 m）は 0 年で安全側すぎ、60 年で危険側
- テイルリスク（費用・発生率は仮定）: L1 の CVaR90 12 → 20 → 37%（60 年は S2 が 30.5 ポイント）、L2 は約 80% で頭打ち、
  年期待損失 0.057 → 0.083 → 0.178 %/年（60 年は S2 が 63%）、年 1/1000 の損失 16 → 20 → 40%。
  費用のばらつき β 0.4 を入れた確率密度では L1 の CVaR90 12 → 21 → 41%、L2 85 → 92 → 97%

## 仮定（既定値）

- 利用方法: 1-A（フェーズ 1、載荷重 0）・2-A（2、10 kN/m²）・3-C（3、20 kN/m²）、接岸力 500 kN・牽引力 350 kN（1,000〜3,000 GT 級）
- 余震 kh 0.15（L1・L2 とも）、土留部（控え直杭式矢板と仮定）0.30 / 0.50 m、段差 0.10 m・渡版の開き 0.20 m は緊急復旧の注意事項
- 杭頭の局部座屈は既定で利用不可。εcu は式B（0.44·t/R − 0.0026、下限 εy）、Lp = D
- 劣化・地震・土留部の分布は README の D4・G4 と報告書 3 章のとおり（抽出は乱数の種 1、項目ごとの乱数系列、年数の間で共通）
- テイルリスク: 復旧費 杭頭の局部座屈 20、地中部を含む 40、杭の塑性化 10、梁の Mu 15、耐力不足の補強 10、土留部 10 / 25、緊急復旧 1（上限 100）、
  L1 年 1/75・L2 年 1/1000、確率密度の費用のばらつき β 0.4（examples/kawasaki_tailrisk.py の COST・RATE・COST_BETA）

## 実行方法（Linux のクラウド）

```
pip install -r requirements.txt            # numpy, scipy, pyyaml, pytest
pip install matplotlib                     # テイルリスクの図だけに使う
python -m pytest -q                        # 360 件（G4 時点）
python -m rcframe.deterioration_report examples/kawasaki_guideline   # 報告書を作り直す（results を読み、判定をやり直す）
python examples/kawasaki_tailrisk.py       # テイルリスクの図（日本語フォントが要る。例: apt-get install fonts-noto-cjk）
python examples/kawasaki_guideline.py -j 6 # 計算のやり直し（6 並列で正味 5〜6 時間。結果があれば飛ばして再開する）
```

- examples/kawasaki_guideline/results（G4 の結果、CSV・JSON Lines 約 17 MB）はコミット済み。
  D4 の results（examples/kawasaki_deterioration/results、約 13 MB）と古い結果フォルダ（kawasaki_results* など）はローカルにだけある
- ローカルでは Windows のため、git は "C:\Program Files\Git\cmd\git.exe"、Python は .venv（matplotlib はシステムの Python）を使っていた
